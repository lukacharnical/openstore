# OpenStore - Configuré avec votre Serveur Personnel Firebase

Ce dossier contient votre application OpenStore directement liée à votre base de données personnelle **`openstore-be393`**.

## 🚀 Comment mettre à jour votre site sur GitHub Pages :

1. Téléchargez et dézippez cette archive.
2. Allez sur votre dépôt GitHub : `https://github.com/lukacharnical/CharnicalLuka-APK`
3. Cliquez sur **Add file** > **Upload files**.
4. Déposez-y le nouveau fichier `index.html`.
5. Cliquez sur **Commit changes**.

### ✨ Résultat :
Toutes les applications ajoutées sur le site depuis n'importe quel téléphone ou ordinateur seront sauvegardées directement sur votre serveur Realtime Firebase et ne seront plus jamais effacées !
